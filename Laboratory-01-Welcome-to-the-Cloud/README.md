# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to the Linux environment and basic cloud computing tools. I used the KillerCoda Playground to work with Ubuntu Linux and prepared a GitHub repository as my Cloud Computing Portfolio.

## Objectives

- Access and use a cloud-based Linux environment.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

- Accessed the Ubuntu 24.04 environment using KillerCoda.
- Created and logged in to a Linux user account.
- Checked the username, working directory, and hostname.
- Gathered Linux distribution, kernel, CPU, memory, and disk information.
- Created files and directories using Linux commands.
- Created and organized the Cloud Computing Portfolio on GitHub.

## Linux Commands Used

- `whoami` – displays the current username.
- `pwd` – displays the current working directory.
- `hostname` – displays the hostname.
- `uname -r` – displays the kernel version.
- `lscpu` – displays CPU information.
- `free -h` – displays memory information.
- `df -h` – displays disk space information.
- `mkdir` – creates directories.
- `ls` – lists files and directories.
- `cat` – displays file contents.

## Skills Learned

Through this activity, I learned basic Linux commands, file and directory management, system information gathering, Markdown documentation, and GitHub repository organization.
